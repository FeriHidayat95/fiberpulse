# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within FiberPulse, please do not open a public issue.
Instead, send an email to `security@fiberpulse.io` or reach out via GitHub Security Advisories.

All security vulnerabilities will be promptly addressed.
